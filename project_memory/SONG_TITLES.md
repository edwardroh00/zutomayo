# 즛토마요 곡명 프로젝트 메모리

공개 원곡 71곡의 일본어·영문 공식 제목과 나무위키 한글 표시 제목을 저장했다. 공식 확인 커버·참여곡·매시업·발표곡 7건은 별도 분류한다. 같은 곡의 라이브·인스트·어쿠스틱·재편집 버전은 새 원곡으로 세지 않는다.

## 읽기 및 사용 원칙

- **한글 표시 제목은 사용자 요청에 따라 나무위키 표기를 그대로 사용한다.** 개별 곡 문서의 제목을 우선하고, 개별 문서에서 찾지 못하면 디스코그래피 전곡 목록을 사용한다. 띄어쓰기를 임의로 고치지 않는다.
- 나무위키 표기를 공식 한국어 제목으로 인증하지 않는다. JSON의 title_ko는 프로젝트 표시용, title_ko_official은 공식 현지화 확인용 별도 필드다.
- 나무위키에 영문으로만 쓰인 곡(Dear. Mr「F」, Ham, JK BOMBER, MILABO, TAIDADA, Blues in the Closet, lowmotion algae 등)은 그대로 유지한다.
- 일본어 원제·영문/로마자 제목과 공식 별칭은 이전 공식 근거를 유지한다. 예: お勉強しといてよ = 공식 MV STUDY ME / 음원 Obenkyou Shitoiteyo.
- 한글 이름으로 요청된 곡은 이 목록에서 일본어·영문 제목과 매칭한다. 나무위키 내부의 다른 한글 표기는 JSON 별칭에도 보존한다.
- 상세 매칭과 출처는 [SONG_TITLES.json](./SONG_TITLES.json), 한글 원문 발췌는 [NAMUWIKI_KOREAN_TITLES.json](./NAMUWIKI_KOREAN_TITLES.json), 공식 제목 근거는 [SONG_TITLE_EVIDENCE.json](./SONG_TITLE_EVIDENCE.json)에 있다.

## 출처별 표기 차이

- 馴れ合いサーブ의 개별 곡 문서 제목은 **짜고 치는 서브**, 디스코그래피 전곡 목록은 **친숙한 서브**로 다르다. 표시 제목은 개별 문서를 따르고 다른 표기도 별칭으로 보존한다.
- 消えてしまいそうです는 개별 문서의 **사라져 버릴 것 같아요**를 사용하며, 목록의 **사라져버릴 것 같아요**도 별칭으로 보존한다.
- 나무위키 전곡 목록에 またね幻가 まてね幻, ろんりねす가 るんりねす로 적힌 부분이 있다. 한글 표시만 참고하고 일본어·영문 공식 제목은 바꾸지 않는다.
- DB의 アンチモン 영문 antinomy는 공식 antimony와 달라 공식 표기를 사용한다. クリームで会いにいけますか의 일본어 표기도 공식 원문을 유지한다.
- 暗く黒く의 MV DARKEN / 음원 Darken, ミラーチューン의 MV MIRROR TUNE / 음원 Mirror Tune 등 공식 별칭은 JSON에 보존한다.
